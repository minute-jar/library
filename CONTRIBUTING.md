# Contributing to the Minute Jar public library

> **Draft.** These rules follow those of the main Minute Jar repository and will be refined as the project grows.

- Use the words of [GLOSSARY.md](GLOSSARY.md) in code, tests and messages.
- Read the [decision records](docs/adr/) that touch your area; to change a settled decision, open an issue first.
- Every commit is signed off under the [Developer Certificate of Origin](https://developercertificate.org/): `git commit --signoff`.
- Never name a child, a family device or a private host in code, tests, issues or commits. Test data use invented names only.
